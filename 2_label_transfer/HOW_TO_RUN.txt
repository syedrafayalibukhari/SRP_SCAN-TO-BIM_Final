STEP 2 - LABEL TRANSFER AND TILING
==================================

What it does
  Gives every point of preprocessed.ply a starting label and a confidence (0 = unsure, 1 = sure),
  using the trained model in the "model" folder. No training is needed. Then writes the floor as
  tiles or as one file, ready for manual correction in step 3.

  Classes: floor, ceiling, wall, door, window, column, partition, other, curtain wall.

1. Choose tiling (optional)
   By default the whole floor is written as one file. For a large floor or a computer with little
   memory, open label_transfer.py in a text editor and change near the top:
        TILE_SIZE_M = 0
   to 8 (8 m x 8 m tiles). Save the file.

2. Open a command window in this folder and run:
        python label_transfer.py
   The script uses preprocessed.ply from this folder or from ../1_preprocessing.
   To use another file:
        python label_transfer.py --input my_floor.ply

Options
  --tile-size 8             tile size for this run instead of TILE_SIZE_M (0 = no tiling)
  --input NAME.ply          point cloud to use
  --output-folder NAME      folder for the results (default labelled)

Results (folder "labelled")
  tile_rXX_cYY.ply             one file per tile (row XX, column YY)
  labelled_floor.ply           the whole floor in one file (tile size 0, the default)
  tile_map.png                 top view coloured by starting label with the tile grid (tiles only)
  label_transfer_report.txt    label shares, confidence and point counts per tile

Notes
  - The starting labels are approximate and must be corrected in step 3.
  - model/model_info.json lists the accuracy check of the model per class. Doors and columns are
    the weakest classes, so check them first.

Other scripts
  train_label_model.py        retrains the model from one or more labelled floors:
                                  python train_label_model.py floor1.ply floor2.ply
  convert_legacy_labels.py    converts a floor labelled with the earlier twelve classes:
                                  python convert_legacy_labels.py old.ply new.ply
  split_glass_labels.py       splits window points into windows and curtain walls without manual
                              labelling. Run step 5 on the floor first, then:
                                  python split_glass_labels.py floor.ply components.json new.ply
                              A glazed run that reaches the floor becomes curtain wall; a run with
                              a sill stays window.
